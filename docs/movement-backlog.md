## Intake Queue

Raw intake currently comes from `/Users/jackmichaels/Desktop/buttons/workouts.txt`. Treat that file as an input scratchpad, not as the agent ownership source. Agents should claim rows here, use the canonical ID, and only mark `completed` after both source JSON files exist and validation passes.

Status values:

- `queued`: ready for one agent to research and add.
- `claimed`: one agent owns the row and should be allowed to finish or report a blocker.
- `needs_variant`: too ambiguous for a research agent until the exact setup is chosen.
- `duplicate`: already covered by an existing movement or split into existing variants.
- `completed`: source JSON, research JSON, local anatomy meshes, build, and validation are done.

Canonical naming rule: use the least confusing exercise name for the visible `name`, keep common gym shorthand in `aliases`, and make the `variant` sentence precise enough that a researcher knows exactly which movement is being studied.
